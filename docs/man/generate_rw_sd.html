Generate a pomp::rw_sd specification from a model file

Description

Discover model parameter names from a pomp_object_<model>.R file (or an explicit model_file) and construct a pomp::rw_sd object programmatically.

Usage

generate_rw_sd(
  reg_rw,
  ivp_rw,
  model = NULL,
  model_dir = "dynamical_model/fitting",
  model_file = NULL,
  extra_rw = NULL,
  profile_var = NULL,
  remove_delta = TRUE
)

Arguments

reg_rw Numeric. Default/random-walk standard deviation to apply to regular parameters (e.g. 0.03).
ivp_rw Numeric. Standard deviation to apply to initial condition parameters (used inside an ivp(…) call, e.g. 0.1).
model Optional character. Short model name used to find pomp_object_<model>.R in model_dir. Ignored if model_file is provided.
model_dir Character. Directory where model files live (default: dynamical_model/fitting).
model_file Optional character. Absolute path to a model file. If provided this is used instead of model/model_dir.
extra_rw Optional named vector or list of overrides. Names are parameter names. Values may be numeric (regular rw sd) or language/call objects (for example call(“ivp”, 0.05)). Setting a value to NA removes the corresponding rw entry.
profile_var Optional character or vector of parameter names to exclude from the returned rw.sd (useful when profiling parameters).
remove_delta Logical. If TRUE remove delta from the rw list (we generally do not fit human mortality in these models). Default: TRUE.

Details

The function creates regular random-walk standard-deviation entries for estimated parameters (par_names) and ivp(…) entries for initial condition parameters (vp_names). Call objects (language) are used for ivp(…) entries so no eval(parse(…)) is required.

Value

An object of class rw.sd (as produced by pomp::rw_sd).
